# Monte Carlo Simulations — Notes

This script simulates portfolio value paths under configurable return/volatility assumptions and summarizes terminal value outcomes and drawdown behavior.

## What it demonstrates
- Simulation-based risk analysis
- Distribution-aware portfolio thinking
- Downside probability estimation
- Maximum drawdown diagnostics

## Outputs
The script saves:
- simulated path chart
- terminal value distribution histogram
- pathwise maximum drawdown distribution
- CSV summaries
